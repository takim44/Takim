# Takim — NRX Coin Platform Concept

A simple demo website for an NRX Coin mining + trading + instant transfer platform idea.

## Features included

- NRX blockchain platform landing page
- $1000 investment plan section
- $50/day user pool concept section
- Live-updating NRX price simulation (up/down)
- Instant user-to-user payment simulation form (0-second target UX)

## Run locally

Open `index.html` in your browser.
